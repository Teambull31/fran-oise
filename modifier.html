Dernière étape

Vos modifications sont prêtes. Il reste à les envoyer sur le site, en trois clics.

Publier à la main (si la publication directe ne marche pas)

  1. Un onglet s’ouvre sur une page remplie de texte.
  2. Dans cette page : tout sélectionner (Ctrl + A), coller (Ctrl + V), puis cliquer sur le bouton vert « Commit changes » en haut à droite.

Le site se met à jour tout seul une à deux minutes plus tard.

Publier en un clic

À régler une seule fois. Ensuite, le bouton « Publier maintenant » enverra tout — textes et photos — sans passer par aucune autre page.

Il faut un « code d’accès » que GitHub fournit. C’est une longue suite de lettres et de chiffres, à créer une fois puis à coller ici.

  1. Ouvrir la page de création du code
  2. Donner un nom, par exemple Modifier mon site.
  3. À « Repository access », choisir Only select repositories puis Teambull31/fran-oise.
  4. À « Permissions » → « Repository permissions » → Contents, choisir Read and write.
  5. Cliquer sur Generate token, puis copier le code affiché.
Ce code permet de modifier le site : gardez-le pour vous. Il reste sur cet ordinateur et n’est envoyé qu’à GitHub.
